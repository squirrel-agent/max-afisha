## Что обязательно заполнить вне исходного архива перед фактической сдачей

Следующие значения невозможно честно зафиксировать без конкретного production deployment/репозитория:

- ссылка на работающего чат-бота/mini-app в MAX;
- public HTTPS URL собственного API;
- Git repository URL и commit hash (если сдаёте через Git; для архива — приложить контрольную сумму);
- рабочие значения environment для технической проверки передаются только предусмотренным организаторами способом, а не в исходном коде;
- PDF-презентация с техническим первым слайдом и продуктовой частью.

Не подставляйте фиктивные URL/токены: после deployment внесите реальные значения в презентацию и при необходимости в submission-specific копию `DATA-API.yaml`.
